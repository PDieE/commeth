Commeth Utils 一款业务相关的工具函数库

# 🎉 Features

- 基于 Vue 3.5+
- 基于 TypeScripts

# 📦 Installation

```shell
# NPM
npm i @commeth/utils
# PNPM
pnpm add @commeth/utils
```

# 🔨 Usage

```js
import { withInstall } from "@commeth/utils";

export const Component = withInstall();
// some component
```
