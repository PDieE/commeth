Commeth Components for Ant Design Vue 是基于Ant Design Vue实现的业务组件库

# 🎉 Features

- 基于 Ant Design Vue 4.2.x
- 基于 Vue 3.5+

# 📦 Installation

```shell
# NPM
npm i @commeth/components-antv
# PNPM
pnpm add @commeth/components-antv
```

# 🔨 Usage

```js
import { createApp } from "vue";
import { SimpleWrap } from "@commeth/components-antv";

import App from "./app.vue";

const app = createApp(App);
app.use(SimpleWrap);
```
